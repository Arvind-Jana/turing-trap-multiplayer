## 🌟 Overview & Concept

**Turing Trap** is a fast-paced, real-time multiplayer social deception party game (inspired by *Jackbox Games* and *Among Us*). 

In each round:
1. **The Prompt**: Players receive a hilarious dilemma tailored to student life, career navigation, or tech culture (e.g. *"Explain why you should be hired over a hyper-intelligent calculator in 2 sentences"*).
2. **Secret Writing**: Human players type their answers while an undercover AI agent secretly generates an answer in the background.
3. **The Lineup**: All submissions are anonymously displayed in random order on all players' screens.
4. **The Vote**: A 30-second live countdown begins! Players must debate and vote on: **Which response was generated by the AI Bot?**
5. **The Reveal**: Staggered unmasking reveals the true Bot, rewards human detectives (+100 pts), awards deception bonuses (+50 pts) to humans who tricked their friends, and crowns the top detectives on an animated 3D podium with confetti celebrations!

## 🚀 Quick Start (Local Setup)

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)
- npm (comes with Node.js)

### 2. Install & Run
```bash
# Clone or navigate to the directory
cd Turing-Trap

# Install dependencies
npm install

# Start the game server
npm start
```

Open your browser to:
👉 **`http://localhost:3000`**

### 3. Playing the Game
- **Host a Room**: Click "Host Room", pick an avatar and name, and click "Create Host Room".
- **Invite Friends**: Click **"Copy Link"** in the lobby to send friends the direct room link (`http://localhost:3000/?room=CODE`).
- **Solo Testing Mode**: Alone? Simply click **"🤖 Add Simulated Friend"** in the lobby to immediately add autonomous simulated players and test all game mechanics without needing a second device!

## 🌐 1-Click Cloud Deployment (Free)

You can deploy Turing Trap publicly in under 2 minutes:

### Option A: Render.com (Recommended)
1. Push this folder to a GitHub repository.
2. Sign in to [Render.com](https://render.com) and click **New + > Web Service**.
3. Select your repository.
4. Configure:
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
5. Click **Create Web Service**. Your live URL will be ready immediately!

### Option B: Railway or Glitch
- Import repository into [Railway.app](https://railway.app) or [Glitch.com](https://glitch.com). Both detect `package.json` and start the server automatically with WebSocket support enabled.
